# OpenGrad Brand Guidelines

This document serves as the official brand and UI reference guide for OpenGrad.

## Color Palette

The OpenGrad color palette consists of seven main colors that range from deep teal to bright yellow. These colors should be used to establish brand identity and provide clear visual hierarchy in the user interface.

| Swatch | Color Description | Hex Code |
|---|---|---|
| • | **Dark Teal** - Primary base or background color. | `#034852` |
| • | **Deep Teal Green** - Primary accent for elements like links and buttons. | `#006d6c` |
| • | **Medium Green** - A secondary or alternate action color. | `#209379` |
| • | **Vibrant Green** - Highlights, call-outs, and successful actions. | `#0abe62` |
| • | **Light Lime Green** - Sub accents, soft highlights, or background overlays. | `#a6db74` |
| • | **Bright Yellow** - Attention-grabbing color for critical alerts or specific call-to-actions. | `#ffde00` |
| • | **Soft Yellow** - Accents and backgrounds, a warmer tone for hierarchy. | `#ffde59` |

### General Usage Guidelines
*   The teals and greens should serve as the primary foundational colors of the interface.
*   The vibrant green is for highlighting key information.
*   The yellows are reserved for special accents and alert states.
*   When overlapping, ensure high contrast between colors and text for accessibility.

## Typography

The OpenGrad type system defines specific fonts for headings/sub-headings and body copy to ensure readability and consistent brand tone.

### Headings & Sub-headings

Use these geometric sans-serif fonts for a strong and modern brand presence. Preferred for titles and subtitles.

*   **Norwester:** Bold, geometric sans-serif (all-caps recommended based on style guide visual).
*   **Greycliff Bold:** A sturdy geometric sans-serif.
*   **League Spartan:** Geometric sans-serif with a bold, uniform weight (all-caps recommended).
*   **Oswald:** Re-working of the classic 'Alternative Gothic' type styles, good for a slightly condensed look.

### Body Copy

Use these highly legible sans-serif fonts for paragraphs and other descriptive content.

*   **Montserrat:** A classic geometric sans-serif with excellent readability across weights.
*   **Telegraf:** A versatile and modern geometric sans-serif with a technical feel.
*   **Arial:** The standard system fallback font.

## Logos

The OpenGrad logo consists of a wordmark and a logomark. The defining feature is the stylized graduation cap incorporated above the letters 'O' and 'G'.

### Logo Usage Guidelines
*   The primary full logo (Wordmark and Logomark combined) is the preferred representation of the brand.
*   The stand-alone logomark (graduation cap icon) can be used for compact spaces, favicons, or on-brand decorations.
*   Ensure the white or reversed-out versions of the logo and logomark are used on dark backgrounds for proper visibility.

### Logomark Variants
*   **Primary Mark:** Color (Teal) or Black on light backgrounds.
*   **Reversed Mark:** White version on dark backgrounds.
